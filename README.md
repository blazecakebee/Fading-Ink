# Fading Ink

A browser life-sim inspired by BitLife-style games, with a cultivation twist: hidden sects, Qi realms, Gates full of spirits, and generational play.

Play: open the GitHub Pages URL for this repo (Settings → Pages → deploy from `main`).
Local: run `python3 -m http.server` in this folder and open http://localhost:8000. Opening the HTML file directly won't work because ES modules need a server.

## Structure
```
index.html            app shell
css/main.css          layout, components, combat screen, responsive/ultrawide rules
css/themes.css        14 UI themes (CSS variables)
js/main.js            boot + wires UI hooks into game systems
js/settings.js        options model (themes, sliders, toggles) applied as CSS vars/classes
js/core/              rng, save/load (localStorage), UI hook bus
js/data/              countries, traits (8 tiers), realms/sects/manuals, careers, combat moves/enemies/loot,
                      activities (Actions + Social actions), random yearly events
js/systems/           life loop (aging, school, jobs, death, inheritance), people/NPCs, traits, cultivation
js/ui/                render (all tabs), portrait generator, combat UI, modals, fx, settings & legacy panels
js/audio/             synthesized SFX + original generative music stations, plus "load your own music"
js/net/coop.js        peer-to-peer co-op rooms (host relays; chat, hang out, gym, Qi training, spar, sect invites, dating, marriage, shared children)
js/vendor/            PeerJS 1.5.5 (MIT, see PEERJS-LICENSE.txt)
assets/icons.png/json 83 16x16 icons from Angais/pixel-art-atlas-1.4m (CC0)
tools/pick_icons.py   script that searches the dataset and rebuilds the icon sheet
```

## Co-op
One player opens the Co-op tab and clicks **Create room**; others type the 5-letter code. The host's tab must stay open. PeerJS's free cloud server only connects players; game data goes browser-to-browser. For local testing you can run your own PeerJS server and add `?peerhost=127.0.0.1&peerport=9000` to the URL.

## Releasing an update
1. Bump `VERSION` in `js/version.js` and add an entry at the top of `CHANGELOG`.
2. Put the same number in `version.json`.
3. Commit and push. Open games check `version.json` every minute, show a notice, save, and refresh themselves.

## Cloud saves (Google)
1. Go to https://console.cloud.google.com → create a project (e.g. "Fading Ink").
2. APIs & Services → Library → enable **Google Drive API**.
3. OAuth consent screen → External → add the scope `.../auth/drive.appdata` → add yourself and friends as test users.
4. Credentials → Create credentials → OAuth client ID → **Web application** → Authorized JavaScript origins: `https://blazecakebee.github.io`.
5. Copy the Client ID (ends in `.apps.googleusercontent.com`) into `js/cloud-config.js`. Never commit a client secret.
Saves go to a hidden app folder in each player's own Drive. Connecting always merges with local saves.
